The problem

Coding agents keep rediscovering the same repository facts.

Agents often need to rediscover structure, important files, symbols, dependencies, callers, tests, routes, and architecture facts before they can make a focused edit.

RepoMind makes that repository intelligence persistent and reusable, while keeping the source tree authoritative.

Capabilities

Built for practical agent discovery.

Automatic Freshness

Read commands check saved changes before answering, so context can reflect current files.

Task-aware ContextPack

Focused context for a coding task, including likely files, symbols, tests, and relationships.

Explainable Retrieval

Ranking can include inspectable signals such as path, symbol, graph, route, and memory evidence.

Repository Memory

Durable local facts with provenance, confidence, evidence paths, and freshness state.

Dependency / Caller / Impact Analysis

Conservative static relationships help agents inspect nearby dependencies and likely impact.

MCP Integration

A local MCP server exposes status, context, stats, memory, symbols, callers, dependencies, and impact.

Local-first / Private

The index lives in local SQLite. Normal operation does not upload source or require telemetry.

Provider-neutral Metrics

Stats report local estimates for observability, not provider billing tokens or credit savings.

How RepoMind works

  1. Repository

  6. ContextPack
  7. CLI / MCP
  8. AI Coding Agent

Privacy model

Local by default, with clear boundaries.

  • RepoMind stores its intelligence index in local SQLite under the repository.
  • Normal indexing and retrieval do not upload source code.
  • RepoMind does not send telemetry.
  • No external AI API is required for normal operation.
  • The source tree remains authoritative; RepoMind output is discovery guidance.

FAQ

Short answers, careful claims.

What is RepoMind?

RepoMind is a local-first repository intelligence layer for AI coding agents. It indexes repository metadata, symbols, relationships, architecture facts, and memory into a local SQLite cache.

Does RepoMind upload my code?

Normal RepoMind operation does not upload repository source. Validation reports are local until a tester chooses to share sanitized results.

Does RepoMind require an AI API?

No external AI API is required for normal indexing or retrieval.

Does RepoMind replace Codex/Copilot/Claude?

No. RepoMind is not a coding agent. It provides local repository context that agents and developers can inspect before editing source.

What is Repository Memory?

Repository Memory stores durable local facts with source evidence, category, confidence, timestamps, source type, and freshness status.

Why is the audit more expensive than setup?

Setup and Audit use the same RepoMind software. The audit adds human architecture analysis, repository mapping, validation, written findings, prioritized recommendations, and findings handoff. A short walkthrough can be arranged if needed.

Is RepoMind production-ready?

RepoMind is beta software. Developers should test it on repositories they own or control and use normal care with pre-release developer tools.

Does RepoMind guarantee AI credit savings?

No. Token measurements are local estimates, not provider billing tokens, account credits, or guaranteed savings.
