# RepoMind v2.0.0b13 — public beta release notes

Publication status: release candidate prepared for owner review. This document does not establish that b13 has been published. Use only assets actually attached to the canonical GitHub Releases page; b12 remains the currently published beta until a separate release is approved.

## Changes

### P0-A: TypeScript shared harness recovery

Recover runnable test suites that consume shared harnesses without recommending standalone execution of non-executable shared-case helpers. Apply graph budgets fairly and report truncation when limits are reached.

### P0-B: Component-aware filename matching

Avoid unrelated selections caused by generic stems such as index, main and common while retaining legitimate component-specific test matches.

### P0-C: Conservative Go fallback

Recognize changed *_test.go files as tests. Go dependency-graph extraction, runner integration and native test selection remain unsupported. Report unknown production coverage and never fabricate Go test commands.

### P1-A: Python test selection

Reduce facade-only over-selection, preserve directly changed tests and verified dependency relationships, and retain broad fallback commands.

### Security and reliability

Preserve symlink/junction containment and bounded static analysis with explicit uncertainty and truncation. RC2 corrects an adversarial test to use the existing symlink-reader contract; this correction does not change product behavior. The build backend requires setuptools>=70.0.0; qualified builds used newer constrained tooling. RepoMind remains local-first and analysis-only, without telemetry, hosted services or execution of recommended commands.

## Qualification and compatibility

The frozen RC2 passed 403/403 source tests on Windows Python 3.11.9 and 403/403 installed-wheel tests on an isolated, digest-verified Astral CPython 3.13.18 build. Native Windows real-symlink assertions passed 19/19 with no skips, and junction cases passed 4/4. Ruff, strict mypy, CLI/MCP smokes, explicit JavaScript/TypeScript/TSX grammars, pip check and a third-party advisory audit passed. The unpublished RepoMind package itself was excluded from the PyPI advisory audit; this is not a complete source-security assessment.

Linux real-symlink assertions previously passed 19/19 under WSL Python 3.14.4. That version is outside advertised 3.11–3.13 classifiers. Patched Linux runtime and macOS qualification were not part of the local RC2 run. The PR workflow is configured to test Linux 3.11–3.13 and installed-wheel behavior on Linux/Windows; consult the exact PR commit checks for actual CI outcomes.

Package metadata permits Python>=3.11, while classifiers advertise 3.11–3.13. The open lower bound permits installation on newer versions and is not a claim that every newer runtime has been qualified. No platform promise was expanded.

## Upgrade from b12

See [the b12 upgrade guide](../UPGRADE_B13.md). Download only an actually published b13 asset, compare its exact published SHA-256, and install that wheel in the existing isolated RepoMind environment. The unrelated PyPI project named repomind is not this repository's distribution.

No GitHub release, PyPI publication or website deployment is performed by preparing this branch.
