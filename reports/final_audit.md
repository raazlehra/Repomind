**Appendix — How to reproduce locally**
1. Create a venv and install dev extras:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e .[dev,watch,treesitter]
```

2. Run tests and checks:

```powershell
pytest -q
python -m mypy repomind
ruff check .
```

3. Run evaluator and baseline tools:

```powershell
python -c "import sys, runpy; sys.path.insert(0, '.'); runpy.run_path('tools/evaluate_retrieval.py', run_name='__main__')"
python -c "import sys, runpy; sys.path.insert(0, '.'); runpy.run_path('tools/compute_baseline.py', run_name='__main__')"
```
